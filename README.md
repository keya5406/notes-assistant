# Notes Assistant

A RAG (Retrieval-Augmented Generation) based chatbot for querying pre-uploaded notes on an existing platform.

## Tech Stack

- **Backend**: FastAPI
- **LLM**: Gemini API
- **Vector Database**: Qdrant Cloud
- **Embedding Model**: Sentence Transformers (all-MiniLM-L6-v2)

## Features

- Retrieve relevant notes using vector similarity search
- Generate contextual responses based on uploaded documents
- Fast and efficient API endpoints
- Cloud-based vector storage
